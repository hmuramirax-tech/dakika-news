## 2. Feature Prioritization

### MoSCoW Method
| Priority | Description | Action |
|---|---|---|
| **Must** | Critical for launch | Fix immediately |
| **Should** | Important but not blocking | Fix this sprint |
| **Could** | Nice to have | Fix if time permits |
| **Won't** | Not this release | Add to backlog |

## 3. Release Checklist

### Pre-Release
- [ ] All critical bugs fixed
- [ ] All high bugs fixed or have workarounds
- [ ] `flutter analyze` — 0 issues
- [ ] `flutter test` — all tests pass
- [ ] Performance targets met
- [ ] Release notes written

### Release
- [ ] Build release APK
- [ ] Test on low-end device
- [ ] Distribute to beta users
- [ ] Monitor for 24 hours

### Post-Release
- [ ] Collect feedback
- [ ] Fix any regressions
- [ ] Update documentation
